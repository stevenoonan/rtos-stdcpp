# Licensing and dependencies

The [component notices](../THIRD_PARTY_NOTICES.md) describe the licenses for the
bundled code. Project code uses the root [MIT license](../LICENSE). FreeRTOS,
Arm and GCC files retain their own terms and copyright notices. The GCC Runtime
Library Exception is in
[COPYING.RUNTIME](../third_party/libstdcxx/stm32-gcc-14.3.1-cxx17/COPYING.RUNTIME).

The component notices also record source references and local modification notes.

Applications supply their own RTOS kernel and port, including their applicable
license notices. The library does not bundle ThreadX kernel sources.
